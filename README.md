# Chic Running Carreras

Página de la carrera **Flores y Kilómetros** de ChicRunning, con información del evento y presentación de sus auspiciadores.

## Uso local

Abre `index.html` directamente en el navegador. La página también puede ejecutarse mediante cualquier servidor web estático.

## Estructura

- `index.html`: contenido principal.
- `styles.css`: diseño responsive y estilos visuales.
- `app.js`: renderizado de auspiciadores.
- `sponsors.json`: datos para servidores web.
- `sponsors-data.js`: respaldo para abrir la página mediante `file://`.
- `assets/sponsors/`: logotipos de los auspiciadores.
